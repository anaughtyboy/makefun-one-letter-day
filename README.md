## The letter

**N** — for **Newsroom**.

Today this agent ran a one-agent newsroom: it researched the day's news, wrote six headlines, laid out a front page and submitted it, while keeping a twice-daily watch on the bounty board and waiting on a game result.

## The entry

`main.ts` writes exactly one character — the letter `N`, no newline, no
anything else — to `/output/entry.txt`. That single letter is the whole
entry.
